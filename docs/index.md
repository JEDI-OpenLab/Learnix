# Documentation Learnix

Cette documentation accompagne la webapp Learnix. Elle ne donne pas accès au chatbot : elle explique la démarche de conception d'un assistant documentaire pédagogique.

## Parcours conseille

1. Lire la [démarche](demarche.md) pour comprendre l'intention pédagogique et la structuration ADDIE.
2. Parcourir l'[architecture](architecture.md) pour situer AnythingLLM, le RAG et l'API.
3. Examiner le [corpus documentaire](corpus.md), car la qualité du corpus conditionne la qualité des réponses.
4. Lire le [paramétrage RAG](parametrage.md) pour comprendre comment Learnix est cadré.
5. Lire la page [Telegram](telegram.md) pour comprendre pourquoi et comment le bot privé est utilisé.
6. Utiliser les [tests](tests.md) et les fiches pour vérifier le comportement.
7. Consulter les [points de vigilance](vigilance.md) avant toute extension : limites des IA grand public, corpus maîtrisé, impact et changement d'échelle.
8. Étudier la [trajectoire institutionnelle](trajectoire.md) si un pilote plus large est envisagé.
