# Corpus Learnix

Ce dossier sert à documenter le corpus. Il ne doit pas nécessairement contenir tous les documents sources, notamment lorsque ceux-ci ne sont pas diffusables publiquement.

## Ce qui peut être publié

- liste des documents utilisés ;
- métadonnées ;
- thèmes ;
- statut public ou privé ;
- liens vers sources publiques ;
- notes sur la qualité d'import ;
- version du corpus.

## Ce qui ne doit pas être publié sans vérification

- documents sous droits non redistribuables ;
- documents internes ;
- données personnelles ;
- exports bruts d'AnythingLLM contenant des chemins, identifiants ou traces techniques ;
- fichiers issus d'un scraping non relu.

## Recommandation

Utiliser `fiches/corpus-manifest.example.yml` comme base pour tenir un inventaire propre du corpus.
