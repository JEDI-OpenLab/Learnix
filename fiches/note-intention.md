# Note d'intention

Learnix est un démonstrateur d'assistant documentaire en ingénierie pédagogique.

Il repose sur une idée simple : dans un contexte où les outils d'IA générative deviennent ordinaires, il ne suffit pas de discuter abstraitement de leurs risques ou promesses. Il faut construire des objets concrets, les tester, documenter leurs limites et s'en servir pour ouvrir une discussion pédagogique.

Learnix n'a pas vocation à devenir immédiatement un service public. Le chatbot reste privé. Ce qui est partagé ici, c'est la démarche :

- installation d'un outil RAG ;
- constitution d'une base documentaire maîtrisée ;
- paramétrage strict du comportement ;
- tests de refus hors corpus ;
- analyse des limites ;
- réflexion sur un éventuel pilote institutionnel.

La question centrale n'est pas seulement : "que peut faire l'IA ?"

Elle devient :

> À quelles conditions un assistant IA peut-il soutenir la conception pédagogique sans se substituer aux enseignants, aux ingénieurs pédagogiques ou aux cadres institutionnels ?
