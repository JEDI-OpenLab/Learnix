# Scénarios de démonstration

## Scénario 1 : refus hors corpus

But : montrer que Learnix n'est pas un chatbot généraliste.

Question :

```text
Qui a gagné la Coupe du monde 1998 ?
```

Message à faire passer :

Learnix peut refuser une question même lorsque le modèle distant connaît probablement la réponse. C'est une fonction de confiance, pas un échec.

## Scénario 2 : question pédagogique simple

But : montrer l'intérêt d'une base documentaire interrogeable.

Question :

```text
Quels principes retenir pour construire un alignement pédagogique cohérent ?
```

Message à faire passer :

Learnix aide à retrouver et structurer des idées issues du corpus, sans remplacer le jugement pédagogique.

## Scénario 3 : question complexe d'accompagnement

But : montrer le potentiel de médiation.

Question :

```text
Comment accompagner un enseignant qui souhaite revoir son évaluation dans un contexte d'IA générative ?
```

Message à faire passer :

Learnix peut proposer une première structuration de discussion, mais l'accompagnement humain reste central.
